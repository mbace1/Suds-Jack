# Reference

`conrad.png` — Conrad B. Hart's animation frames from Flashback (SNES),
ripped by LuigiBlood and published on The Spriters Resource. It is here as a
**reference for the animation**, not as art the game ships: nothing in
`flashprince/` loads it, and no pixel of it reaches the screen.

Flash Prince has no sprites in it at all — a pose is thirteen joint angles and
a frame is those angles turned into filled polygons (see `js/figure.js`). This
sheet is what those angles are measured off, the same way Chahi measured
Another World's off film of himself. Delphine Software own the original
artwork.
