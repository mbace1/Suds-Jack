# Slay Kallio

Early visual seed for a new side-view project, built by salvaging TURF concepts that are useful outside TURF's isometric-facing rules.

The first collection is deliberately concept-only. It preserves character identity, silhouette, clothing, props and side/profile motion ideas without treating any of these sheets as final production sprites.

## Why this exists

TURF explicitly rejects near-profile / side-scroller poses. Some otherwise useful character work was therefore wrong for TURF but potentially valuable for a side-view game. Slay Kallio is the place to preserve and evaluate that material instead of discarding it.

## Initial buckets

- `concepts/from-turf/profile-rejections/` — TURF attack frames explicitly documented as near-profile and unsuitable for TURF's authored isometric facings.
- `concepts/from-turf/context/` — cast contact sheets for identity/context.
- `concepts/library-sideview/` — prior side-view / four-direction / profile-oriented TURF concept sheets, normalized as review copies.

## First production question

Before converting anything into final sprites, Slay Kallio should lock a horizontal side-view camera, common character height, floor baseline, left/right facing convention and animation scale. Then the strongest identities and motions in this archive can be rebuilt cleanly for the new game.
