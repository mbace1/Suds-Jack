# Slay Kallio — Recovered Art Asset Pool v0.3

This is the consolidation point for the art made/recovered around TURF, Piritori/Kallio and the cardboard/craft visual direction that can feed Slay Kallio.

## Core Slay Kallio rule

Characters are primarily **rounded standing cardboard cut-outs with flat bottoms**. A front or front-3/4 TURF illustration can be printed directly onto the standee. Normal locomotion does not require a conventional walk cycle: the standee moves horizontally and can use small whole-card bob, tilt, lean and wobble. New frame art is reserved for meaningful actions such as attack, hit, interaction and KO/fall-flat.

This makes the existing front-facing concept pool just as important as the old side/profile material.

## Production priority

1. Front/front-3/4 character concepts → default cardboard standees.
2. Side/profile concepts → alternate poses, attacks, special actions, edge-on flips and optional authored left/right states.
3. T-pose/turnaround concepts → identity, clothing and prop truth.
4. Kallio environment atlases → rebuild as layered cardboard/paper theatre scenery.
5. Craft references → define material response: matte print, fibrous paper, worn edges, corrugation, folds, tape, slots and shallow physical shadows.

## Low-frame target

A basic character can begin with:

- 1 default standing standee
- 1–3 attack/action images
- 1 hit/wobble image if needed
- 1 KO/fall image

Movement itself can remain transform-driven. Add frames only when they materially improve action readability or character personality.

## Source status

All recovered images are **concept/reference inputs**, not automatically final production art. Preserve the strongest identity and Kallio specificity while converting them into the Slay Kallio cardboard system.
