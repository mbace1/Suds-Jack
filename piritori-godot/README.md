Piritori → Eden — a narrative strategy game set in Kallio, Helsinki, 2003 (Dope
Wars × Mini Metro × East of Eden). All state lives in one `localStorage` key on
this device; nothing leaves the browser and nothing is required to play. Source
is [mbace1/piritori-eden](https://github.com/mbace1/piritori-eden), built from
commit `de48cd5` (2026-08-25).
