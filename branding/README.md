## Face reference (both brands)
- `toko/master/face-yellow-on-white.jpg` (main, 700×700): the owner's master Toko face. This is the canon per `toko/BRAND.md` §2c, and it is the same trace the RFH studio clay `tokoBadge` uses (`radiofree/studio/clay/puppets.js`, branch `claude/radio-free-helsinki-pvtsw5`). ## Radio Free Helsinki (`radio-free-hki/`)
- Colours: ochre `#e3a33a`, magenta `#f0027f`, night `#0d0f16`.
- Banners (v2, minimal, per Mikael's feedback): a flat `#0d0f16` field, the wordmark in off-white, and ONE accent: a thin magenta `#f0027f` rule. No photo or skyline. On the X header the wordmark is placed right so the avatar has room at the bottom left.
- Profile icon (approved, unchanged): a papercut skyline and radio mast drawn in `make.py` behind the badge.
- Badge: the Toko face in white on a magenta disc, mirroring the studio's `tokoBadge`. The repo has no raster RFH logo; `radiofree/icon-512.png` is a pixel Toko-Move character. The wordmark is set in DejaVu Sans Bold.
