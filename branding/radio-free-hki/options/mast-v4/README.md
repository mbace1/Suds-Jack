# RFH mast icon v4: refinements of v3-5 (duotone ochre dusk)

These are options only and aren't applied anywhere. Each has a `-1080.png` square and a `-circle.png` crop. `contact-sheet.png` shows each one at 400, 64 and 48px. Regenerate with `python3 make_mast_v4.py`; it reuses the helpers in `../mast-v3/make_mast_v3.py`.

- **v4-1 clean-low**: a cleaner silhouette. The mast sits lower with more sky, over one low rooftop ridge with the cathedral. The night waves are crisp with rounded ends, and the magenta tip is small and tight.
- **v4-2 warm-strong-glow**: a warmer honey-to-burnt-orange sky with a low sun glow behind the skyline. The mast is lower, and the magenta tip is larger with a clean pink halo.
- **v4-3 pure-silhouette**: no rooftops, only a flat night horizon. The mast is larger, heavier and set low, with four tapering crisp waves and a small, sharp tip light.
