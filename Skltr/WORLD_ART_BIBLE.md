# SKLTR WORLD ART BIBLE — v52

## Thesis
The world is not a sequence of decorated arenas. It is one unstable videogame reality rebuilding itself around movement. Arena transitions are the signature visual event.

## Constants
- Player and enemy silhouettes remain readable through every world state.
- Gameplay floor and traversal edges always read before decoration.
- The Toko face is the player's fixed identity anchor; do not reinterpret the expression.
- World transformation happens between combat spaces, not as noisy combat obstruction.
- Props must explain movement, lanes, height or world scale. No filler clutter.

## State 1 — VECTOR VOID / HOUND RUN
Black negative space, luminous construction lines, sparse impossible towers, concentric range/grid traces. Fastest and cleanest state. Low geometry around the player. The arena should feel unfinished but intentional, like the simulation is exposing its skeleton.

## State 2 — BRUTAL SYNTHETIC / TORTOISE HEIGHTS
The wireframe fills into massive pale architectural slabs. Long walls, terraces, cuts and opposing raised masses create lanes. Heavy, graphic, almost paper/concrete material response. Tortoises visually belong to the architecture and anchor firing corridors.

## State 3 — BIO-SIGNAL / WASP LIFT
Architecture stretches into vertical pylons, rings and machine-organic antenna forms. Dark violet depth with bright signal edges. Repetition bends and rotates. Vertical reading becomes the composition: player eye is pulled upward without filling the combat floor with clutter.

## State 4 — PHYSICAL MACHINE WORLD / MACHINE YARD
The game becomes unexpectedly material: heavy grey structures, believable mass, loading-yard proportions and grounded horizon blocks. Still surreal in arrangement, but closest to a real physical place. This contrast should make the previous abstract states feel like layers underneath reality.

## State 5 — KILL STATE / FINALE
Previous languages collapse together. Red-black void, pale hot edges, rings and monoliths. Avoid adding visual density simply because it is the finale. The danger comes from enemy ecology; the environment frames it.

## Transformation grammar
1. Combat clears.
2. Existing representation loses certainty: edges remain while fills recede or vice versa.
3. Horizon mass changes first so the destination becomes obvious.
4. Traversal begins while structures assemble/fold/stretch.
5. New arena floor remains readable throughout.
6. Final state locks before the next meaningful projectile pattern begins.

Preferred transformations: extrusion, folding slabs, wire-to-solid fill, ring expansion, vertical growth, material replacement, horizon reconstruction. Avoid generic fades as the main effect.

## Arena composition rules
### HOUND RUN
Open center. Low interruptions. Hounds approach across visible space and invite dash-through melee. Architecture sits mainly at perimeter and behind enemy approach lines.

### TORTOISE HEIGHTS
Two strong lane choices. Raised masses and long blockers. Tortoise positions should visually read as gun emplacements. Player can cross lanes through deliberate openings rather than wandering through random boxes.

### WASP LIFT
Clear ground escape routes plus strong vertical landmarks. Flying enemies framed against negative space. Vertical architecture must never camouflage projectile silhouettes.

### MACHINE YARD
Mix the learned problems: lanes, pursuit and vertical pressure. Physical-looking masses make navigation intuitive before the finale destabilizes the world again.

## Character / enemy integration
Player: stylized humanoid, exaggerated readable proportions, abstract arcade costume, Toko face fixed, bunny ears optional accessory only.

Enemy world evolution should change surface language more than silhouette:
- Hound: vector skeleton -> slab-armored -> signal tendon -> physical machine.
- Tortoise: outlined turret animal -> architectural block -> antenna organism -> industrial emplacement.
- Wasp: line glyph -> folded graphic insect -> luminous signal creature -> mechanical drone.

Do not create variants that compromise role recognition.

## Production order
1. World-state runtime language.
2. Finished HOUND RUN composition.
3. Finished TORTOISE HEIGHTS composition.
4. Transform between those two without a loading/fade feeling.
5. WASP LIFT and MACHINE YARD.
6. Enemy material/evolution pass.
7. Player final model and canonical Toko face source integration.
8. Finale collapse state.

## Definition of done for the first art milestone
A screenshot from HOUND RUN and a screenshot from TORTOISE HEIGHTS should look like two radically different worlds, while a player can immediately identify the same game, same combat language and same traversal priorities in both.
