## 1. The loop

**clip** (daily, carries this week's frequency) → **TUNE** it on the site → **chapter** (a dystopian story, played straight) → **the job**: a challenge in one cabinet → **the secret** (a fragment + a card you can post) → next clip.

## 2. Stage A — the clips, automated

1. **Set the secret.** Without it there is no daily wire and nothing to clip.
2. **`radiofree-clips.yml`**, after the wire: check out `gh-pages`, `render-day.mjs --lang fi,en,ja --seconds 18`, ffmpeg to H.264 (`-crf 18`, `loudnorm` check), keep the **LEAD** and **ODD WIRE** per language, upload as artifacts. ~21 renders a day, 1–2 h of CI; free on a public repo.
3. **The social cut** lives in `film.js`, not in ffmpeg, so a clip stays "the thing that shipped": an `ending` for export — the Toko badge/sting (~1.2 s), the fiction line, and `TUNE 104.7 · link in bio`. **Safe zones:** the fiction footer sits 96 px from the bottom edge, inside TikTok's caption band; the social cut lifts footer and card text into the middle 70 % of the frame.
4. **Hosting:** the last 14 days on `gh-pages` under `radiofree/clips/<date>/` (needed for the Instagram API and for the site to embed), pruned by the job; older ones stay as Action artifacts (90 days). 18 s H.264 ≈ 5 MB; 14 days × 3 langs × 2 clips ≈ 400 MB. Long-term archive is an owner decision (§6).

## 3. Stage B — the socials

- **Accounts:** one handle on both (proposal: `@tokomidorigames`, to be checked). Avatar = the badge (`toko/index.html` exports the SVG). Bio = the cry + the terms + the link. Instagram links live **in the bio** (and Stories' link sticker); TikTok's bio link needs a Business account.
- **Posting:** Phase 1 **by hand** from the day's artifact (ten minutes a day). Phase 2 the Instagram Graph API publishes Reels straight from the `gh-pages` URL — needs an Instagram professional account tied to a Facebook Page and a Meta app. TikTok's Content Posting API needs an app audit; until then by hand.
- **Captions:** generated by the wire job next to each bulletin — headline, the DECODE tell, the fiction line, the week's frequency — in `EDITORIAL.md`'s voice, ≤ 5 hashtags. **Labels:** *fiction · satire* in the caption and burned in; mark it AI-assisted (the copy is model-written) — on brand, since the creed is *built with AI, out loud*.
- **Cadence:** TikTok daily (the LEAD); Instagram four Reels a week plus Stories; a weekly *frequency reveal* post. Measurement is platform-side only: the site keeps *nothing leaves the browser*, so code entries cannot be counted unless the owner wants the feedback transport (`hub/feedback.js`) pinged once per unlock, anonymously.

## 4. Stage C — the narrative experience (a new cabinet)

Working title **DEAD AIR** — the carrier gone, RFH's own sign-off. Folder `deadair/`, house rules: vanilla modules, no build step, no image assets, fi/en/ja with the trilingual gate, `hub/shell.js` HOME, the Toko signature, a cabinet and marquee in `hub/games.js`, `VERSIONS.md`.

**A season is 8 chapters, one a week.** Each is a story from inside the broadcast's world — the half-step dystopia of `EDITORIAL.md`, everything invented, played straight — in three beats:

1. **TUNE.** A dial. This week's frequency (printed on every clip that week) opens the chapter. Toko speaks in the codec panel — `toko/js/chat.js`'s Sierra-style counter, dialogue tree and typed parser, dropped onto the page; the mask is the face and he has no body (`BRAND.md`, `toko-live/CANON.md`). Topics you reach *by your own words* stay locked otherwise, which is already how the counter works.
2. **THE JOB.** A challenge in one cabinet, deep-linked (`../hyperdagger/?job=static-1`); **games are unchanged in phase 1**. On return the chapter reads the cabinet's own best or its playlog. Season 1 uses the eight cabinets with a readable seam: Hyper Dagger (seconds), Toko Drop, Drop Cabal, Flowsnow, Powder, Paper Route, Flash Prince (best time), CONCRETE (points). Thresholds come from the run histories, never guessed.
3. **THE SECRET.** A story fragment, a shareable **card** drawn in code (1080×1920 PNG — the way back into the feed), and the next week's teaser. Codes are derived from the week number and a salt, so there is no server and no account.

Progress is `localStorage`; a typed code carries it across devices. Optional hook: each day's clip carries one letter; seven letters open a bonus secret on Sunday. Phase 2 adds one playlog event per game for richer jobs (TURF: extract the crew; Toko Move: finish a shift).

Gates: bare-node tests for codes and chapters, a Playwright walk of the whole loop, the trilingual check, and the hub smoke test.

## 5. Build order — one commit each, each with its gate

1. The secret (owner, five minutes) → the wire is daily again.
2. `radiofree-clips.yml` + the H.264 pass → a daily artifact. 1–2 days.
3. The social ending and safe-zone footer in `film.js`. 1 day.
4. Accounts; the first week posted by hand (owner).
5. DEAD AIR: the engine, chapter 1, two cabinets. 3–4 days; then one chapter a week.
6. Instagram API publishing, once the Meta app exists.

## 6. Decisions only the owner can make

1. Set `ANTHROPIC_API_KEY` in the repo's secrets.
2. The handle, and who holds the accounts.
3. Voice: silent with captions (now), the owner's own recording, or a paid TTS — Finnish and Japanese have no good free voice.
4. The name: DEAD AIR, THE CARRIER, or STATIC.
5. Clip retention: 14 days on `gh-pages`, or an external bucket.
6. Posting by hand for the first month, while the API approvals run.
