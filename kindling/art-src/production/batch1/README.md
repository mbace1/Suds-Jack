# Betterment production assets — Batch 1

These are native PNG production assets, not presentation boards.

Rules:
- binary alpha only (0/255)
- no baked labels, captions, frames or card backgrounds
- no baked fire/firelight in A1–A4
- A1–A4: 320×180
- B/D: 40×40 cells on 400×160 sheets
- E/F: 512×256 atlases

See `MANIFEST.json` for layout and `VALIDATION.json` for dimensions, alpha checks and hashes.
