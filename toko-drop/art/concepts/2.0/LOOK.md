# Toko Drop 2.0 — Look for Claude

Watercolor concept sheets = **shape/layout only**, not a forced in-game shader.

## Three styles (gallery / picker)

1. **Watercolor** — mood / painted look (active concept path).
2. **3D cel-shaded** — clean readable flats + soft edges (valid production option).
3. **3D textured** — more surface detail (later).

Do **not** treat “not cel-shaded” as a ban. Cel-shaded is style option 2.

Default placeholder meshes can stay simple/readable until Mikael picks a style for a build. Jelly/gel translucency still fits all three.
