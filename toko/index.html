Who is signing this

Toko Midori is the masked artist behind the look of every cabinet in this workshop. The mask is not a gimmick — it is the terms. You do not get a face, a founder story or a personal brand to buy into. You get the work, and the work is free, in a browser, with no account.

Toko is not against the machine. Toko is holding one — these games are built with AI, out loud, on purpose, and nobody is pretending otherwise. What Toko is against is the machine becoming the audience: a world where everything is generated and nothing is made, where people scroll output instead of cutting their own.

So the identity shows its seams on purpose. Every mark here is painted in code — there is not one image asset in this brand — and every mark is allowed to tear, drop out and lose the signal, because a thing that is obviously constructed is a thing you can obviously build yourself.

Use the tools. Take the source. GO MAKE YOUR OWN.

The marks

One 24×24 grid, three deliverables: the screen mark, the SVG logo file, and a 16×16 reduction that is redrawn rather than resampled. The SVG is generated from the same string art the canvas draws, so the file you hand someone can never drift from the thing on screen.

Registers

A mark is drawn in exactly one of four. LIVE is the default. STAMP is the signature. GHOST is for 16px and print. RIOT only ever exists on the frame a hit lands on — it is never a resting state.

The palette

One green held against a near-black void, a hanko red for the signature, and the two phosphors the games already speak in — borrowed, and never used as Toko's own colour. If a mark needs a sixth colour, the mark is wrong.

The alphabet

5×7, cut by hand. The brand owns its letterforms outright: no font file to license, to load, or to fail to load. Anything the identity ever needs to say, it says in these.

A–Z · 0–9 · . , ! ? - : ' / · ×

The glitch

Seeded, so the same hit lands the same way twice — a glitch you cannot reproduce is a bug wearing a costume. Below about 0.25 the mark should read clean: the glitch is an event that happens to the mark, so most of the time it is not happening.

The sting

    
Three seconds of signal finding a face — noise resolves into
    the mask, the mask takes a hit, the seal comes down, the name types itself
    out. Skippable on any input from the first frame: a sting you cannot skip
    is an ad, and Toko does not run ads.

Lockups

    
How Toko sits beside a cabinet: the mask, a hairline, the
    name, and the game underneath it in the game's own colour. Toko
    never takes the game's accent and the game never takes the green.

    

  


  


  

    
Signing a page

    
One import. It stamps the seal into a corner, sits under the
    HUD, never takes input unless you give it an href, holds a 44px
    tap target when you do, and paints a single still frame for anyone who has
    asked for reduced motion.


<script type="module">
  import { sign } from '../toko/js/signature.js';
  sign();                                  // bottom-left, non-interactive
  // sign({ corner: 'bottom-right', href: '../toko/' });
</script>
