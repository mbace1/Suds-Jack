# Hyper Dagger — platform

One fast-FPS core. Three modes.

| Mode | Reference | Rules |
|------|-----------|-------|
| **PURE** | Devil Daggers | Fixed spine, one-touch, edge void, no dash, gem thieves |
| **HYPER** | Hyper Demon | Clock, dash, REAP, kill time floor, density ramp |
| **TRUCK** | Clustertruck | Auto-scroll platforms, fall death, dash, hazards |

Shared: player body, dagger gunfeel, input, voxels + optional Meshy GLBs.
